# Análisis de Controles de Seguridad en el SDLC

## Estudiante
Mauricio Jurado

## Asignatura
Seguridad del Software

## Objetivo

Analizar los controles de seguridad que deben implementarse durante cada fase del Ciclo de Vida del Desarrollo de Software (SDLC), utilizando como caso de estudio un Sistema Web de Citas Médicas.

## Aplicación seleccionada

Sistema Web de Citas Médicas que permite a los pacientes registrarse, solicitar, consultar y cancelar citas médicas, mientras que el personal de salud administra la agenda de los profesionales de la salud.
